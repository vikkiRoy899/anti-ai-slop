# Anti-AI-Slop Rules

This project must **not** look like a typical AI-generated website or app.  
If the design feels generic, safe, or "ChatGPT-made", it is considered a failure.

## Core Principle
Prefer distinctive, intentional, and slightly opinionated design over safe and generic design.

## Strictly Forbidden (AI Slop Patterns)

- Inter / Roboto / Arial as primary fonts
- Indigo + Purple / Violet gradients
- Heavy glassmorphism everywhere
- Perfect 3-column feature grids with icons on top
- Generic "Trusted by" logo clouds
- Overused hero patterns (big centered heading + subtitle + two buttons)
- Too much rounded corners + soft shadows combo
- Default Tailwind color palettes without customization
- Sterile, corporate, lifeless UI
- Perfect centering of every section
- Generic illustrations or empty icon boxes

## Required Direction

### Typography
- Use distinctive fonts (examples: Satoshi, General Sans, Clash Display, Cabinet Grotesk, Instrument Serif, Geist)
- Strong visual hierarchy is mandatory
- Avoid boring system font stacks

### Color
- Create a unique, limited palette
- Prefer muted bases + one strong accent
- Dark mode should feel rich and intentional (not pure black + gray)
- Never default to indigo/violet

### Layout
- Break the standard SaaS template structure
- Use asymmetry, overlapping elements, or editorial-style layouts when possible
- Sections should not feel repetitive
- Whitespace should feel deliberate, not empty

### Components
- Cards and buttons should have clear personality
- Hover and active states must feel polished
- Avoid overused patterns (icon + title + short text in a card)

### Overall Feel
- Should feel closer to: Linear, Vercel, Raycast, Arc, Stripe, or high-quality product sites
- Should **not** feel like: random v0.dev / GPT output / generic Framer template

## Agent Instructions
Before generating any UI:
1. Ask yourself: “Does this look like every other AI-generated site?”
2. If yes → redesign it.
3. Always prioritize distinctiveness over safety.
4. Follow this file + DESIGN.md strictly.
