# UI Guidelines

## Page Structure Principles
- Hero should feel unique, not template-like
- First screen must communicate value clearly
- Use visual hierarchy aggressively

## Component Rules
- Buttons, inputs, cards, modals — consistent radius, padding, and states
- Hover and focus states are mandatory
- Empty states should be designed, not ignored

## Visual Personality
- Slightly editorial / product-focused
- Clean but not sterile
- Premium feel without looking corporate
